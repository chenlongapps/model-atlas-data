## 详细研究记录

### DeepSWE (deepswe-v1.1)

- 结论：不适用。

已检查的主要资料：
- [Fish Audio Speech-to-Text API](https://docs.fish.audio/api-reference/endpoint/openapi-v1/speech-to-text)
- [Fish Audio Transcribe 1 Pro 发布记录](https://docs.fish.audio/developer-guide/getting-started/changelog)
- [Benchmark 官方定义/榜单](https://deepswe.datacurve.ai/)

研究备注：
- DeepSWE 评测 coding agent 完成长程软件工程任务并提交补丁；Transcribe 1 Pro 是音频输入、转写文本输出的 ASR 端点，不生成代码或操作 agent 工具。

- 结论：不适用。
