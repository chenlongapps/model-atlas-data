## 详细研究记录

### DeepSWE (deepswe-v1.1)

- 结论：不适用。

已检查的主要资料：
- [Nace.AI Drex v2.0 模型卡](https://huggingface.co/nace-ai/drex-v2.0)
- [DeepSWE v1.1 方法](https://deepswe.datacurve.ai/blog/deepswe-v1-1)
- [DeepSWE 官方排行榜](https://deepswe.datacurve.ai/)

研究备注：
- DeepSWE v1.1 要求 coding agent 在隔离容器中编辑代码并提交 patch/commit，由 verifier 检查；Drex 只返回决策概率，不生成代码或 patch。

### SWE-bench Pro (swe-bench-pro-v2)

- 结论：不适用。

已检查的主要资料：
- [Nace.AI Drex v2.0 模型卡](https://huggingface.co/nace-ai/drex-v2.0)

### Chartography (chartography)

- 结论：不适用。

- [Nace.AI Drex v2.0 模型卡](https://huggingface.co/nace-ai/drex-v2.0)

尚未解决的问题：
- 需要确认该 12.8 对应仓库定义的原版 HLE 2,500 题及 accuracy/pass@1 协议；当前不写入 TOML。

### Artificial Analysis Intelligence Index (artificial-analysis-intelligence-index-v5)

- 结论：不适用。

已检查的主要资料：
- [Nace.AI Drex v2.0 模型卡](https://huggingface.co/nace-ai/drex-v2.0)
- [Artificial Analysis Intelligence Index V5 方法](https://artificialanalysis.ai/methodology/intelligence-benchmarking)

研究备注：
- AA Intelligence Index V5 是多项语言/知识工作能力的综合指数，包含工具、代码/终端和开放回答任务；Drex v2.0 只返回结构化决策概率。Nace 的 Decision Index 是不同定义，不能映射为 AA Intelligence Index。

最近核验时间：2026-11-04T04:24+08:00

### GDPval-AA (gdpval-aa-v2.1)

研究备注：
