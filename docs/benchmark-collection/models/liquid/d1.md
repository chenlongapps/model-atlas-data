## 详细研究记录

### DeepSWE (deepswe-v1.1)

- 结论：不适用。

已检查的主要资料：
- [Liquid d1 官方 API 文档](https://docs.liquid.ai/lfm/models/d1)
- [Liquid d1 官方介绍](https://www.liquid.ai/blog/d1-decision-model)
- [DeepSWE v1.1 官方方法](https://deepswe.datacurve.ai/blog/deepswe-v1-1)

研究备注：
- DeepSWE 评测 agent 提交的代码变更，并在隔离环境执行验证；d1 仅输出结构化决策且生成 0 个 token，不能独立生成可验证代码补丁。未发现 exact d1 成绩。

### AutomationBench (automationbench-v1.0.6)

- 结论：不适用。

- [Liquid d1 官方 API 文档](https://docs.liquid.ai/lfm/models/d1)
- [Liquid d1 官方介绍](https://www.liquid.ai/blog/d1-decision-model)
- [Zapier AutomationBench 官方榜单与协议](https://zapier.com/benchmarks)

研究备注：

最近核验时间：2026-11-04T06:09+08:00

最近核验时间：2026-11-04T06:09+08:00

### Chartography (chartography)

已检查的主要资料：

### Humanity's Last Exam (humanitys-last-exam)

- 结论：不适用。

已检查的主要资料：
- [Liquid d1 官方 API 文档](https://docs.liquid.ai/lfm/models/d1)
- [Liquid d1 官方介绍](https://www.liquid.ai/blog/d1-decision-model)
- [HLE 官方评测说明](https://artificialanalysis.ai/evaluations/humanitys-last-exam)

研究备注：
- 仓库目标是原始 2,500 题 HLE；d1 不能对需要短文本答案的题目生成答案。AA 的 HLE-MultiChoice 是从原始集合抽取的 513 道纯文本选择题子集，属于不同测试配置，不能替代原始 HLE 记录。未发现 exact d1 的原始 HLE 成绩。

最近核验时间：2026-11-04T06:09+08:00

### Artificial Analysis Intelligence Index (artificial-analysis-intelligence-index-v5)

- 结论：不适用。

已检查的主要资料：
- [Liquid d1 官方 API 文档](https://docs.liquid.ai/lfm/models/d1)
- [Liquid d1 官方介绍](https://www.liquid.ai/blog/d1-decision-model)
- [Artificial Analysis Intelligence Index V5 官方定义](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)
- [Artificial Analysis Decision Index（不同指数）](https://artificialanalysis.ai/evaluations/artificial-analysis-decision-index)

研究备注：
- d1 属于结构化决策模型；Artificial Analysis Decision Index 是单独的指数，不能映射为 Intelligence Index V5。V5 的语言模型、编码、科学和 agentic 工作制品任务需要生成文本/结果，d1 无法独立完成。未发现 exact d1 的 V5 成绩。

最近核验时间：2026-11-04T06:09+08:00

### Vals Index (vals-index-v2.2)

- 结论：不适用。

已检查的主要资料：
- [Liquid d1 官方 API 文档](https://docs.liquid.ai/lfm/models/d1)
