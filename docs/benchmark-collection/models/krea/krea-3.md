### DeepSWE (deepswe-v1.1)

- 结论：不适用。

### OSWorld (osworld-v2.1)

- 结论：不适用。

已检查的主要资料：
- [Krea 3 官方发布文](https://www.krea.ai/blog/introducing-krea-3)
- [Krea 3 官方 API 文档](https://www.krea.ai/docs/developers/krea-3/overview)

### Chartography (chartography)
