# 文档导航

本目录只维护长期有效的规范、操作说明和核验限制；成绩及参数数值只维护在源 TOML 中。

| 文档 | 用途 |
| --- | --- |
| [数据规范](data-format.md) | 模型、参数量、成绩、成本、定义、汇总与本地化 |
| [开发与校验](development.md) | 环境、测试、TOML / JSON 构建及检查边界 |
| [网页与发布](publishing.md) | 本地预览、图表解读、Pages 部署及 manifest |
| [Models.dev 同步](models-dev-sync.md) | 自动同步范围、描述保护、翻译与故障处理 |
| [评测来源与口径](benchmark-sources.md) | 常用来源、成本字段及不可混用的实验条件 |
| [参数量核验方法](model-parameters.md) | 检查点计数、组件范围及来源限制 |
| [待核实事项与许可](review-notes.md) | 尚无结论的冲突、版本映射和分发风险 |

## 维护约定

- 新增规则写入对应专题，不另建重复规范；操作流程以仓库脚本和工作流为准。
- 不在文档中维护模型总数、成绩副本、覆盖率或执行流水，这些内容容易过期。
- 修改数据前先阅读 [AGENTS.md](../AGENTS.md)；未知字段省略，不为消除警告编造数据或新增定义。
- 临时采集报告不再单独保留；仍有影响的结论汇入专题或待核实事项，历史详情通过 Git 查询。
